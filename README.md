# Filmateca -- David Llamas

## Descripció
Filmateca és una aplicació desenvolupada amb Angular que permet gestionar un catàleg de pel·lícules. L'aplicacio permetrà consultar detalls i aplicar filtres o cerques segons diferents criteris. El projecte es desenvoluparà progressivament al llarg del curs.

## Stack Tècnic
- Angular 18
- Arquitectura Standalone
- SCSS
- Angular routing
- Git i Github

## Prerequisits
- Node.js LTS
- npm
- Angular CLI
